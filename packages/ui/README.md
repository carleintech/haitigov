# HaitiGov UI Package

This package contains reusable React composition primitives and, beginning in
Phase 4B, accessible interface components. It consumes tokens and global styles
from `@haitigov/design-system` but does not own brand-source files.

Applications must import `@haitigov/design-system/styles.css` once at their
root. Components must use semantic tokens, support Haitian Creole and French,
preserve keyboard operation, and meet WCAG 2.2 AA requirements.
