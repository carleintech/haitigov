# Ministry identity framework

The framework defines how future institution-specific identity profiles may be
represented without fabricating official marks or importing unverified assets.

Each profile requires a stable institution ID, display name, optional acronym,
optional color references, optional reviewed mark kind, source URL, review date,
and an explicit review status. A profile is not usable by the UI unless it is
approved for project use and has a source URL.

The framework does not establish that HaitiGov is an official government
platform, and it does not approve national seals, ministry seals, emblems, or
logos. Those remain governed by the branding registry and authoritative-source
review process.
